# Manual de usuario — Recuperar contraseña

**Aplicación:** Relatic / Easy NodeOne  
**Público:** usuarios finales (sin rol técnico)  
**URL Relatic:** https://apps.relatic.org

---

## ¿Para qué sirve?

Si olvidaste tu contraseña, puedes pedir un enlace por correo y crear una nueva **sin ayuda del administrador**.

---

## Pasos

### 1. Ir al inicio de sesión

Abre: https://apps.relatic.org

En la pantalla de **Iniciar sesión**, haz clic en:

**¿Olvidaste tu contraseña?**

### 2. Indicar tu correo

1. Escribe el **mismo correo** con el que te registraste o te dieron acceso.
2. Pulsa **Enviar enlace de recuperación**.

Verás un mensaje como:

> Si existe una cuenta asociada a ese correo, recibirás un enlace para restablecer tu contraseña.

Ese mensaje es **siempre el mismo**, exista o no la cuenta (por seguridad).

### 3. Revisar el correo

1. Abre la bandeja de entrada del correo que indicaste.
2. Si no lo ves, revisa **Spam / Correo no deseado / Promociones**.
3. El enlace es válido unos **45 minutos** y **solo se puede usar una vez**.

### 4. Crear la nueva contraseña

1. Abre el enlace del correo.
2. Escribe la **nueva contraseña**.
3. Vuelve a escribirla en **Confirmar**.
4. La contraseña debe tener **al menos 8 caracteres**.
5. Guarda los cambios.

Si todo salió bien, verás:

> La contraseña fue actualizada correctamente.

### 5. Entrar de nuevo

Vuelve a **Iniciar sesión** con:

- tu correo, y  
- la **nueva** contraseña.

---

## Problemas frecuentes

| Situación | Qué hacer |
|-----------|-----------|
| No llega el correo | Espera 1–2 minutos; revisa spam; confirma que es el correo de tu cuenta. |
| El enlace dice que expiró o no es válido | Solicita uno nuevo desde «¿Olvidaste tu contraseña?». |
| Las contraseñas no coinciden | Escríbelas otra vez; deben ser idénticas. |
| Dice que es muy corta | Usa al menos 8 caracteres. |
| Pedí el enlace varias veces | Usa solo el **último** correo recibido. |

Si tras varios intentos no puedes entrar, contacta al administrador de tu organización.

---

## Qué no hace este proceso

- No envía SMS ni códigos por WhatsApp.
- No usa preguntas secretas.
- El administrador **no** necesita generar tu contraseña para este flujo (salvo soporte excepcional).

---

## Resumen rápido

1. Login → **¿Olvidaste tu contraseña?**  
2. Correo → Enviar  
3. Abrir el enlace del mail  
4. Nueva contraseña + confirmar  
5. Iniciar sesión
