## Declaración

Este paquete es el **contrato oficial** del ecosistema EasyAI.

A partir de esta fecha:

1. Ningún producto inventa un canal paralelo a EasyAI Core.
2. ARP implementa el runtime **contra** estos documentos.
3. LOCAL (y futuros owners) implementan Connectors **contra** estos documentos.
4. Cambios incompatibles requieren **EIS 2.0** (MAJOR) + nuevo ADR.

El término **Connector SDK** en comunicaciones de producto se refiere a este EIS — no a un segundo estándar.
