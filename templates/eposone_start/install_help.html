¿No podés instalar la app?

Esta página es solo ayuda. No vuelve a descargar el archivo.

Pasos generales

  1. Abrí el aviso de Android y pulsá Configuración.
  2. Activá Permitir instalar apps desde este navegador.
  3. Volvé atrás y pulsá Instalar.
  4. Abrí EPosOne e ingresá tu código de instalación.

Según tu teléfono

Samsung

Ajustes → Biometría y seguridad (o Seguridad) → Instalar apps desconocidas → elegí Chrome → permitir. Volvé a Descargas e instalá EPosOne.apk.

Xiaomi / Redmi

Ajustes → Privacidad / Seguridad → Protección de apps → Instalar apps vía fuentes externas → Chrome → permitir. Luego instalá el APK.

Honor

Ajustes → Seguridad y privacidad → Más ajustes de seguridad → Instalar apps de orígenes desconocidos → navegador → permitir.

Huawei

Ajustes → Seguridad → Más ajustes → Instalar apps de orígenes externos → navegador → activar.

Motorola

Ajustes → Apps → Acceso especial / Instalar apps desconocidas → Chrome → permitir.

Realme

Ajustes → Contraseñas y seguridad → Instalar apps desconocidas → navegador → permitir.

Otros / Android 10–15

Buscá en Ajustes “instalar apps desconocidas” o “fuentes desconocidas” y habilitalo solo para el navegador que usaste. El menú cambia por versión de Android.
