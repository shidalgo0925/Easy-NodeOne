    INSTALAR EPOSONE

    1. Tocá Instalar EPosOne abajo (abre el archivo descargado).
    2. Si Android pide permiso, activá Instalar apps desconocidas para este navegador.
    3. Volvé y confirmá Instalar.
    4. Cuando termine, continuá para abrir la app.

    Si no se abre solo: Descargas → EPosOne.apk → Instalar.

    ABRIR Y ACTIVAR EPOSONE

    1. Tocá Abrir EPosOne.
    2. Introducí tu correo y el código de activación.
    3. Tocá ACTIVAR y seguí el asistente hasta tu primera venta.
